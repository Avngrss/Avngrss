## Beyond Playwright Agents

I am writing **Beyond Playwright Agents**, a technical book about building controlled AI-assisted testing systems around Playwright agents.

The book explains how to move from isolated test generation to a structured engineering workflow in which AI agents plan, implement, execute, and maintain tests within explicit boundaries.

Its central topics include:

- planning as a reviewed contract between requirements and implementation;
- clear responsibilities for Planner, Generator, and Healer;
- project context that agents must follow instead of guessing;
- traceability between requirements, tests, execution results, and defects;
- quality gates for generated and modified tests;
- safe healing that restores implementation without weakening the original obligation;
- fail-closed behavior when available evidence is insufficient;
- human approval for decisions that change requirements, scope, or expected behavior.

The core principle of the book is that a passing test is valuable only when it correctly verifies an approved product obligation.

## Playwright Automation and AI-Assisted Testing

I am developing a reusable **Playwright AI Workflow Kit** for controlled AI-assisted automation.

The kit provides a plan-first workflow for requirement analysis, test planning, Playwright test generation, execution, validation, and maintenance. It combines project-specific agent instructions, reusable skills, architecture rules, quality gates, and CI/CD checks.

My work in this area includes:

- stable locators and synchronization through observable application states;
- deterministic test data setup and cleanup;
- cross-browser testing;
- Playwright traces, screenshots, videos, logs, and execution reports;
- flaky test investigation and root-cause analysis;
- automated linting, architecture validation, and quality gates;
- GitHub Actions integration;

## 📖 Beyond Playwright Agents

I am writing **Beyond Playwright Agents**, a technical book about building controlled AI-assisted testing systems around Playwright agents.

The book explores how to move beyond isolated test generation and design an engineering system in which AI agents operate within explicit responsibilities and verifiable boundaries.

Key topics include:

- planning as an executable contract;
- separation of responsibilities between Planner, Generator, and Healer;
- requirements, evidence, and traceability;
- agent authority and project-level constraints;
- quality gates for generated tests;
- safe test maintenance and controlled healing;
- fail-closed behavior when an agent lacks sufficient evidence;
- human-in-the-loop approval for decisions that change requirements, scope, or expected behavior;
- designing project-specific AI-assisted automation systems.

The central principle is simple: **a green test is valuable only when it correctly verifies an approved product obligation.**

## 🤖 AI-Assisted Playwright Automation Kit

I am developing a reusable automation kit for building controlled AI-assisted testing workflows with Playwright.

The kit combines:

- Playwright agents and project-specific AI instructions;
- plan-first test development;
- feature and requirement analysis;
- structured test generation;
- automated quality gates;
- linting and architecture validation;
- execution evidence and reporting;
- controlled test maintenance;
- safe healing rules;
- CI/CD integration;
- traceability between requirements, tests, execution results, and defects.

The goal is to make AI-assisted automation **predictable, reviewable, and maintainable**, rather than allowing agents to modify tests without clear constraints.

# Yury Siadou

QA engineer. Manual testing, API, Playwright with TypeScript, and AI only where the result can still be checked.

I investigate failures in the console, network, and traces, and I write bug reports from that evidence. Automation covers UI and API flows: fixtures, API setup, GitHub Actions, Allure. When AI drafts a plan or a test, the requirement and the expected result stay mine to approve.

## Now

- [Bug Capture Assistant](https://github.com/Avngrss/bug-capture-assistant-extension) is a local Chrome extension. It records a test session and copies a bug ticket from the steps, console, network, and a screenshot.
- **Beyond Playwright Agents** is a book about AI-assisted Playwright testing. The plan is the contract, and a green test still has to match an approved requirement.
- **Playwright AI Workflow Kit** is a TypeScript starter for that workflow in Cursor, with rules, skills, quality gates, and healing that does not weaken the check.

## Next

An AI-assisted k6 setup: workloads, auth, thresholds, and a comparison between runs. The numbers and the conclusion stay visible.

# Yury Siadou

## Quality Assurance Engineer | Manual & Playwright Automation | AI-Assisted QA

I work across manual testing, API testing, and test automation, from the risk on a release down to the check that guards it.

Playwright and TypeScript carry the automated UI and API flows, wired into CI. When something fails I use the console, network traffic, logs, and traces, and the bug report is written from that evidence. AI drafts plans and tests. Requirements, expected results, and the decision to change them stay with a person.

## Manual testing

- Exploratory, functional, and regression testing against requirements and acceptance criteria
- Test strategy and release scope based on product risk
- Scenarios for the happy path, the boundaries, and the states a flow can actually reach
- Bug reports with steps and the evidence behind them: console, network, screenshots, traces
- REST API testing, including auth and OpenAPI or Swagger contracts

## Test automation

- End-to-end UI and API automation with Playwright and TypeScript
- Page objects, fixtures, and helpers, with API setup and cleanup instead of hand-made data
- Locators based on what the user sees, and waits on real conditions instead of fixed timeouts
- Authenticated sessions, network checks, and runs across Chromium, Firefox, and WebKit
- GitHub Actions as a quality gate, Allure for the report, and traces when a run fails

## AI-assisted testing

AI helps with analysis, planning, test drafts, and maintenance. A generated test is useful only when it still checks an approved requirement.

- Plans come from approved requirements, and tests are written against that plan
- Generated and edited tests are reviewed before they count
- A failure is explained from traces, logs, and product behavior before anyone changes the test
- Healing stops when the evidence does not justify a safe change
- Scope and expected behavior change only with a person's approval

## Now

### Bug Capture Assistant

A local Chrome extension for exploratory testing. It keeps the steps, page alerts, console errors, failed requests, and a screenshot, then copies a bug ticket from that session.

[bug-capture-assistant-extension](https://github.com/Avngrss/bug-capture-assistant-extension)

### Beyond Playwright Agents

A technical book about AI-assisted testing built around Playwright. The test plan is the contract for what gets automated. A passing test counts when it checks an approved product obligation, with a clear line from that obligation to the test, the result, and the defect.

### Playwright AI Workflow Kit

A Playwright and TypeScript starter for that way of working in Cursor: rules, skills, plan-first generation for API, UI, and end-to-end tests, test data and auth state, quality gates, failure evidence, controlled healing, and Allure in CI.

## Next

An AI-assisted performance setup on k6: workload profiles, authenticated scenarios, thresholds, and a comparison between runs. AI can help prepare a scenario and read the results. The metrics, the thresholds, and the conclusion stay visible.

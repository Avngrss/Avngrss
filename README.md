## Beyond Playwright Agents

I am writing **Beyond Playwright Agents**, a technical book about the architecture of controlled AI-assisted testing systems built around Playwright agents.

The book goes beyond test generation and examines how to design a complete engineering workflow around Planner, Generator, and Healer. It covers:

- planning as a reviewed contract;
- requirements and product obligations as the basis for automation;
- separation of responsibilities between agents;
- project context, constraints, and agent authority;
- evidence-driven test generation;
- quality gates and structural validation;
- safe maintenance and controlled healing;
- fail-closed behavior when evidence is insufficient;
- traceability between requirements, tests, executions, defects, and releases;
- human-in-the-loop decisions when requirements, scope, or expected behavior may change.

The central principle of the book is that a green test is valuable only when it correctly verifies an approved product obligation.

## Playwright AI Workflow Kit

I am developing a reusable **Playwright AI Workflow Kit** for controlled AI-assisted test automation.

The kit implements a plan-first workflow in which agents analyze approved inputs, prepare a reviewable test plan, generate tests, validate the implementation, and stop when the available evidence is insufficient.

Its architecture includes:

- feature and requirement analysis;
- structured test planning;
- Playwright test generation;
- UI and API test coverage;
- project-specific agent instructions;
- reusable skills and workflow rules;
- automated architecture checks;
- linting and quality gates;
- execution evidence and reporting;
- controlled test maintenance;
- safe healing boundaries;
- CI/CD integration;
- traceability from requirements to test results.

The goal is not autonomous code generation at any cost. The goal is maintainable automation in which AI actions remain constrained, reviewable, and supported by evidence.

## Engineering Principles

- Requirements come before implementation.
- Test plans should define explicit and reviewable obligations.
- A passing test is valuable only when it verifies the correct product behavior.
- Generated tests must preserve the strength of the approved requirement.
- AI agents should operate within explicit responsibilities and authority boundaries.
- Test conclusions must be supported by observable evidence.
- Flaky tests should be investigated rather than hidden behind retries.
- Healing must stop when a safe correction cannot be proven.
- Human approval is required when requirements, scope, evidence, or expected behavior may change.

I am a Quality Assurance Engineer focused on building reliable testing processes across UI, API, and system levels.

My experience combines manual testing, Playwright automation, API validation, CI/CD integration, and performance testing. I am particularly interested in creating AI-assisted QA workflows where AI agents help with test planning, implementation, analysis, and maintenance while remaining controlled by explicit requirements, evidence, quality gates, and human approval.

🧭 Engineering Principles
Requirements come before implementation
A passing test is valuable only when it validates the correct product obligation
Automation changes must preserve the strength of the original assertion
AI agents should operate within explicit authority and review boundaries
Test results must be supported by observable evidence
Flaky tests should be investigated, not hidden behind retries
Quality reporting should explain product risk, not only count test cases
Human involvement should remain at the points where requirements, scope, authority, or conclusions change

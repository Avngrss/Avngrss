## AI-Assisted Testing

I design QA workflows in which AI supports analysis, implementation, execution, and maintenance without silently changing requirements or weakening validations.

- AI-assisted requirements and acceptance criteria analysis
- Test planning and test documentation generation
- Agent-based test planning, generation, verification, and maintenance
- Plan-first workflows based on approved test obligations
- Specialized agents with explicit roles and authority boundaries
- Reusable skills, prompts, rules, templates, and project instructions
- Project context based on approved sources and known facts
- Validation of AI-generated and AI-modified tests
- Automated quality gates for architecture and implementation
- Traceability between requirements, plans, tests, executions, and defects
- Evidence-based failure and product risk analysis
- Controlled healing without weakening the original validation
- Stop conditions when evidence does not justify a safe change
- Human approval for changes to requirements, scope, or expected behavior

The goal is not to make tests pass at any cost. It is to make QA work faster and more systematic while preserving product obligations, test reliability, and human control.

## Current Work

### Beyond Playwright Agents

I am writing **Beyond Playwright Agents**, a technical book about building controlled AI-assisted testing systems around Playwright agents.

The book covers:

- approved inputs and reviewable test obligations;
- the test plan as a contract for implementation;
- agent responsibilities and authority boundaries;
- separation of observed behavior from approved requirements;
- validation of generated tests and execution evidence;
- traceability between obligations, tests, results, and defects;
- safe healing and explicit Stop behavior;
- human approval for decisions that change requirements, scope, or evidence.

Its central principle is that a passing test is valuable only when it correctly verifies an approved product obligation.

### Playwright AI Workflow Kit

I am developing a Playwright and TypeScript starter for controlled AI-assisted test automation in Cursor.

The kit provides:

- plan-first test generation for API, UI, and E2E layers;
- Cursor rules, skills, and slash commands;
- project context and architecture conventions;
- test data preparation and cleanup;
- authenticated state management;
- automated quality gates;
- failure evidence and readable verdicts;
- controlled test healing;
- coverage traceability;
- Allure 3 reporting;
- CI support for GitHub Actions and GitLab CI.

The kit is a practical implementation of controlled AI-assisted automation, not a replacement for engineering judgment.
